🚀 HOW TO USE THESE FILES
════════════════════════════════════════════════════════════════════════════════

STEP 1: READ DOCUMENTATION (Choose Your Path)
  ↓
  Path A: Development Lokal        → Read QUICKSTART.md (5 min)
  Path B: Termux Android Server    → Read TERMUX_SETUP.md (15 min)
  Path C: Production on Cloud      → Read DEPLOYMENT.md (10 min)
  Path D: All Options              → Read SETUP_GUIDE.md (overview)
  ↓

STEP 2: INSTALL & RUN
  ↓
  Local:   pnpm install → pnpm dev   → http://localhost:3000
  Termux:  pnpm install → pnpm start → http://192.168.x.x:3000
  Cloud:   pnpm install → pnpm build → Deploy to Vercel
  ↓

STEP 3: TEST & DEVELOP
  ↓
  Register → Create post → Add comment → Test reactions → Upload file
  ↓

STEP 4: BACKUP TO GITHUB (Optional)
  ↓
  git init → git add . → git commit → push to GitHub
  ↓

STEP 5: DEPLOY TO PRODUCTION (Optional)
  ↓
  Deploy to Vercel → Setup custom domain → Done! 🎉

Error 1: "Don't know where to start"

→ Open: QUICKSTART.md → Troubleshooting section

Error 4: "Database connection error"
→ Check: .env.local has correct DATABASE_URL from Neon

Error 5: "Can't find dependencies"
→ Run: pnpm install (make sure you're in correct directory)

Error 6: "Deploy to Vercel not working"
→ Open: DEPLOYMENT.md → Troubleshooting section
