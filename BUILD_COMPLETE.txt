DATABASE SETUP:
1. Create PostgreSQL database on Neon: https://neon.tech
2. Copy DATABASE_URL from Neon
3. Paste into .env.local
4. Drizzle ORM will auto-create tables on first run

VERCEL BLOB SETUP:
1. Go to Vercel: https://vercel.com
2. Project Settings → Blob
3. Generate BLOB_READ_WRITE_TOKEN
4. Add to .env.local and Vercel environment variables

ENVIRONMENT VARIABLES NEEDED:
- DATABASE_URL              → From Neon PostgreSQL
- BETTER_AUTH_SECRET        → Generate: openssl rand -base64 32
- BETTER_AUTH_URL           → Your app URL
- BLOB_READ_WRITE_TOKEN     → From Vercel Blob
- NEXT_PUBLIC_APP_URL       → Your app URL
